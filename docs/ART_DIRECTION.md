# ART DIRECTION — SERPENT ARENA 비주얼 스타일 가이드

**한 줄 요약:** 어두운 남색 경기장 위에 **같은 재질의 광택 구슬**로 만든 생물들이 움직인다. 화려함보다 선명함, 장식보다 정보.

## 1. 재질과 광원 (모든 그래픽의 기준)

- **단일 재질:** 모든 뱀(플레이어·경쟁자·보스)은 하나의 검수된 구슬 이미지(`body_segment_blue.png`)로 그린다. 색은 `shaders/snake_skin.gdshader`가 색상(Hue)만 교체하므로 명암·외곽선·하이라이트·접지 그림자가 픽셀 단위로 동일하다.
- **고정 광원:** 키 라이트는 화면 **좌상단**. 구슬은 **회전하지 않는다.** 그래서 곡선 구간에서도 하이라이트와 그림자 방향이 흔들리지 않는다. 진행 방향은 그림이 아니라 **눈**으로 표현한다.
- **절차적 요소도 같은 규칙:** 눈의 반사광, 보스 뿔의 명암은 같은 좌상단 광원(`LIGHT_DIR = (-0.6, -0.8)`)과 같은 짙은 동색 외곽선을 쓴다.
- **먹이:** 같은 광택 구 계열의 원본 리소스. 하이라이트 방향이 뱀과 같다.

## 2. 실루엣과 비율

| 부위 | 규칙 |
|---|---|
| 크기 | 반지름 = 13 × Lv^0.28. Lv10→Lv1,000이 3.6배. 카메라 줌은 반지름^0.8에 반비례해서, 커질수록 작은 뱀이 확실히 작아 보인다 |
| 머리 | 몸통 구슬의 1.22배. 눈 2개가 진행 방향 앞쪽 30%, 좌우 40% 위치 |
| 눈 | 흰자 + 피부색 계열 짙은 테두리 + 동공. 동공은 바라보는 대상(목표·입력 방향)을 따라 움직이되 뒤를 보지 않는다. 2~5초마다 깜박임 |
| 몸통 | 구슬 간격 = 반지름의 0.55배 (겹친 구슬 사슬). 렌더 상한 140개를 넘으면 간격을 넓혀 **시각 길이 = 논리 길이**를 유지 |
| 꼬리 | 마지막 9개 구슬이 42%까지 부드럽게(√ 곡선) 가늘어짐. 별도 꼬리 이미지 없음 |
| 보스 | 같은 구슬, 짙은 진홍 + **몸 뒤쪽 절반에만** 3구슬마다 금색 띠(쇼다운 약점), 금색 뿔 2개, V자로 찌푸린 눈꺼풀, 호박색 홍채 + 세로 동공, 머리 밑 은은한 붉은 글로우. 몸 길이는 같은 레벨 일반 뱀의 0.45배 (짧고 두껍게) |

## 3. 색상 팔레트

**경기장:** 바닥 `#0E1422` + 점 패턴(원본 타일), 바깥 `#070B14`, 경계선 `#4A8FEB`, 경계 안쪽 30% 그림자 띠

**스킨 (Hue 회전, 재질 동일):**

| Teal / Emerald / Gold / Violet / Rose | 0.48 / 0.36 / 0.13 / 0.76 / 0.93 | 플레이어 해금 스킨 (최고 Lv 60 / 150 / 400 / 800 / 1,500) |
| Emerald, Amber, Violet, Crimson, Rose, Teal | | 경쟁자 |

**UI:** 패널 `#0F1726`(86%), 테두리 `#22314A` 1px, 본문 `#E8EEF7`, 보조 `#8A9AB3`, **강조색은 하나** `#3FA2FF`, 위험 `#FF5A52`, 보상/보스 `#FFC64A`

## 4. 가독성 규칙

- 이름표는 월드가 아니라 **화면 공간**에 고정 크기로 그린다 (줌과 무관하게 읽힘).
- **레벨 숫자 색 = 싸움의 결과:** 나를 칠 수 있으면 **빨강**, 내가 칠 수 있으면 **초록**, 같으면 흰색, 나는 하늘색.
- **보호막:** 보호 중인 뱀은 머리에 푸른 반투명 거품이 생기고, 남은 0.5초 동안 서서히 사라진다. 닿아도 안 잘린 이유가 항상 보인다.
- **전투 숫자:** 타격 지점에 "CUT −45%"(내가 침), "−32%"(내가 맞음), "SWALLOWED!", "SHIELD", "ZONE −6%"가 떠올랐다 사라진다.
- **위협 링:** 나를 물 수 있는 뱀의 머리에는 얇은 빨간 링이 붙는다 (가까울수록 진함). 색만이 아니라 형태로도 구분되므로 색각 이상 사용자도 알아볼 수 있다. 위험한 것은 "입"이라서 링도 머리에만 붙는다.
- 화면에서 머리가 6px보다 작은 뱀(피라미)은 위협이 아니면 이름표를 숨긴다.
- 먹이는 아무리 줌아웃해도 화면 기준 반지름 2.6px 아래로 줄지 않는다.
- 이름표는 몸통 반대편에 놓는다 (몸이 위로 뻗으면 머리 아래). 겹치면 우선순위(플레이어 > 보스 > 나머지)대로 비켜 쌓고, 화면 밖으로 잘리지 않게 고정한다.
- 큰 뱀이 작은 뱀 위에 그려진다 (레벨순 정렬).
- 보스가 화면 밖에 있으면 화면 가장자리에 방향 표시 + 거리.

## 5. 이펙트 원칙 (규칙 27-7)

| 상황 | 연출 | 목적 |
|---|---|---|
| 먹이 획득 | 먹이가 머리로 빨려 들어가며 축소 → 몸통을 따라 **삼킴 혹**이 꼬리까지 이동 | 획득 사실 + 몸이 살아 있는 느낌 |
| 희귀/보석 | 작은 흰 반짝임 + 맑은 2음 | 특별 보상 |
| 레벨업 | 금색 링이 머리를 따라가며 퍼짐 (0.45초에 1회 제한), HUD 레벨 숫자 펄스, 몸 밝기 플래시 | 성장 만족감, 남발 방지 |
| 물기 | 물린 지점 금색 버스트, 물린 뱀이 붉게 물들고 밀려남, 흘린 먹이, 내가 물리면 화면 가장자리 옅은 붉은 비네트(0.55초) + 킬 피드 "-N%" | 손실·획득이 즉시 읽힘 |
| 삼킴(처치) | 버스트 + 연기 + 희생자 색의 먹이로 분해 | 승패가 즉시 읽힘 |
| 몸통 충돌 | 미끄러짐 (연출 없음) | 무해함을 과장하지 않음 |
| 절단 | 잘린 뒤쪽 몸통이 즉시 사라지고 그 자리에 희생자 색 먹이가 줄지어 생김 | 잘림이 한눈에 보임 |
| 자기장 | 구역 밖 푸른 장막(24%), 밝은 경계선, 다음 원 흰 점선, HUD 구역 패널, 미니맵 | 다음 이동을 미리 계획 |
| 구역 밖 | "RETURN TO THE ZONE" + 패널 붉은 점멸 + "ZONE −N%" + 가장자리 붉은 비네트 | 위험을 즉시 인지 |
| 쇼다운 | 시계가 빨간 SHOWDOWN으로 바뀜, 최종 원 축소, 보스 카드 "DODGE THE JAWS, CUT ITS GOLD TAIL" | 최종전 전환과 공략 안내 |
| 사망 | 머리부터 꼬리로 구슬이 무너지는 0.55초 디졸브 | 상황 전달 |
| 부활 | 포털 링 + 3초 반투명 깜박임 + "PROTECTED" | 무적 상태 명시 |
| 보스 돌진 예고 | 0.7초 감속 + 글로우 확대 + 저음 | 위협을 읽고 피할 수 있게 |

- 동시 스프라이트 이펙트는 풀 36개로 상한. 파티클 시스템을 쓰지 않는다.
- 일반 먹이에는 발광 없음. 글로우는 희귀/보석과 보스에만.
- 화면 흔들림은 설정에서 끌 수 있고, 플레이어 관련 큰 사건에만 쓴다.

## 6. UI 원칙 (규칙 27-5)

- 폰트: Windows 내장 **Bahnschrift**(→ Segoe UI → Arial)를 `SystemFont`로 사용. 폰트 파일을 배포하지 않는다.
- 모든 글자·숫자는 `Label`/Theme로 렌더. 이미지에 합성된 글자는 쓰지 않는다.
- 버튼 4상태(기본/호버/눌림/비활성) + 키보드 포커스 테두리. 주 버튼만 강조색 채움.
- 그라데이션은 메인 메뉴의 좌측 가독성 음영 1곳에만 쓴다.
- 화면 전환은 0.22초 페이드, 패널 등장은 0.26초 페이드+미세 확대. 과한 바운스 없음.
