## 2026-11-25 — 2차: 플레이 품질 수정 (사운드·추가 콘텐츠 제외)

### 핵심: "부딪혀서 죽는다"를 폐지
- 새 전투 규칙 **"입은 물고, 몸통은 벽이다"**: 몸통 충돌은 미끄러짐, 대등한 머리는 튕김, 더 큰 머리만 **문다**(레벨 차에 비례해 XP를 빼앗음). 약 6배 이상 차이일 때만 삼킴(사망).
- 보스전이 한 번의 접촉 판정에서 **여러 번 물어 깎아내는 싸움**으로 바뀌었다. 보스 레벨은 HUD에 실시간으로 표시되고, 보스는 플레이어만 물 수 있다.
- 보스는 자기 레벨 25% 미만의 피라미를 쫓지 않는다. 큰 뱀일수록 화면상 느리고 덜 민첩하다 (속도 지수 0.4).

### 그 외 수정
- 후반 먹이 무의미 문제 → 일반 먹이 XP를 먹는 뱀의 레벨에 비례시킴 (구슬 1개 ≈ ⅔레벨)
- 부활 페널티 완화 (XP 60% → 75% 유지), 레벨 곡선 완화 (지수 0.25)
- 위험 가독성: 나를 물 수 있는 머리에 빨간 링(형태 신호), 물리면 붉은 틴트 + 옅은 가장자리 비네트 + "-N%" 피드
- 사체 먹이를 적고 크게 (최대 24개), 물리면 소량을 흘림
- 이름표: 몸통 반대편 배치, 화면 밖 잘림 방지
- 코드: `GameSession`에서 `MatchFeedback`(연출)과 `RespawnQueue`(부활)를 분리. `CombatResult`/`BiteRecord` 도입
- AI: 위협은 "더 큰 머리"만, 몸통은 앞에 있을 때만 약하게 회피
- 스킨 메뉴를 열기만 해도 저장 파일을 쓰던 부작용 수정 (`set_pressed_no_signal`)

## 2026-11-25 — 3차: 구조 분리, 절단 전투, 쇼다운, 크기·조작, AI

1. **구조 분리:** GameSession → `MatchDirector`, `ShowdownDirector`, `CombatConsequences`, `DrawOrderSorter`, `AttractCamera` (+ 기존 `MatchFeedback`, `RespawnQueue`). FoodField → `FoodStore`/`FoodField`/`FoodRenderer`. HUD → 구성 요소 7개(`ui/hud/`). 메인 메뉴 → `MenuView` 계열 3개(`ui/menu/`).
2. **전투:** 머리 판정을 "입"(작은 원 + 앞쪽 ±65°)으로 좁혔다. 큰 입이 몸통을 물면 그 지점에서 **절단**되고 잘린 부분은 먹이가 된다. XP 손실은 잘린 비율에 선형. 목 근처(남는 몸 20% 미만)는 삼킴.
3. **쇼다운:** 0:00이 되면 경기를 끝내지 않고 최종 보스전(60초)으로 들어간다. 경쟁자는 먹이로 분해, 경기장 축소, 보스 분노.
4. **AI:** 컨텍스트 스티어링(16방향 위험도 맵), 예측된 위협 입, 몸통 노출 위협, 최선의 타격 지점(목 근처 우선), 먹이 군집 탐색.
5. **크기:** 반지름을 거듭제곱 성장으로 변경(Lv10→1,000이 3.6배). 줌 지수 0.8, 경기장 4,800, 먹이 1,500. 작은 뱀 이름표 숨김, 먹이 최소 화면 크기.
6. **조작감:** 선회 게인 7.5→13, 평활 14→26, 최대 선회 6.2→9.0, 크기에 따른 둔화 지수 0.35→0.5.
7. **조작 안내:** 메인 메뉴 HOW TO PLAY, 경기 시작 6초 안내 카드, 일시정지 화면 조작 목록 (키캡 스타일).

## 2026-11-26 — 4차: 자기장, 타격 판정 명확화, 크기 = 힘, 코드 정리

1. **자기장:** 정규 시간 3단계(대기→축소, 다음 원 미리 공개, 중심 이동) + 쇼다운 최종 단계. 구역 밖에서는 꼬리부터 타서 사라진다(레벨도 하락). 미니맵, 구역 패널, 구역 밖 경고 추가.
2. **판정 명확화:** "머리 앞쪽 절반이 더 낮은 레벨의 어느 부위에 닿으면 반드시 친다" 하나로 정리했다. 판정 원은 그려진 크기에 맞추고(90~95%), 레벨 5% 대등 구간을 없앴다(같은 레벨만 튕김).
   - 안 잘리는 유일한 경우(보호 중)는 **보호막 거품**으로 보여 주고, 접촉 시 "SHIELD"를 띄운다.
   - 타격 지점에 결과 숫자("CUT −45%", "−32%", "SWALLOWED!", "ZONE −6%")를 띄운다.
   - 레벨 색: 칠 수 있으면 초록, 나를 칠 수 있으면 빨강.
3. **크기 = 힘:** 맞으면 남은 몸 길이에 맞는 레벨로 떨어진다. 대신 한 번에 몸 전체가 아니라 **닿은 지점의 덩어리**만 물어뜯기게 바꿨다. 목 타격은 삼킴.
   - 생존 장치: 탈출 가속, 부활 바닥(경기 최고 XP의 40%).
   - 보스: 쇼다운 중 금색 꼬리(약점) 절단, 정규 시간에는 떠도는 위협(어그로 축소, 피라미 무시).
4. **코드 정리:** 미사용 함수 11개 제거, 공개 함수 145개에 문서 주석 추가, 자기장 3개 클래스와 HUD 3개 클래스 추가. `bite_chunk`/`erode`/`cut_at`을 `_shrink` 한 경로로 통일.
- 검증: 45개 테스트 / 299개 검사 통과, 창 모드 18개 화면, 밸런스 프로브 10경기.
